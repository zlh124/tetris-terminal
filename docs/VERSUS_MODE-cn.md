## 对战模式

#### 快速开始

```bash
# 启动服务器
tetris-server

# 玩家1 连接服务器
tetris --server localhost:8765

# 玩家2 连接服务器
tetris --server localhost:8765
```

两个客户端都连接后，服务器会自动匹配双方，对战开始。

#### CLI 命令

| 命令                        | 说明                       |
| --------------------------- | -------------------------- |
| `tetris-server`             | 启动服务器                 |
| `tetris`                    | 联机模式将使用默认端口及ip |
| `tetris --server HOST:PORT` | 设置联机模式连接的端口及ip |

#### `tetris-server` 选项

| 选项        | 默认值    | 说明           |
| ----------- | --------- | -------------- |
| `--host`    | `0.0.0.0` | 绑定主机地址   |
| `--port`    | `8765`    | 监听端口       |
| `--version` |           | 显示版本并退出 |
